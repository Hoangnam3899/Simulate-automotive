# Triage labels

The skills use these five canonical triage roles. Apply the matching GitHub label to issues in `Hoangnam3899/Simulate-automotive`.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | Requires a human decision or implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

When a skill refers to a triage role, use the corresponding GitHub label in this table.
