# Skill Catalog

All skills in this directory. Find the right skill and read its `SKILL.md` before starting work.

## Understanding & Requirements

- **interview-me**: Structured requirement extraction. Use when requirements are unclear or only exist as a vague idea.
- **grill-with-docs**: Relentless interrogation to sharpen a plan + domain doc generation. Use to stress-test an idea.
- **domain-modeling**: Build and sharpen domain glossary (`CONTEXT.md`) and ADRs.
- **spec-driven-development**: Formalize requirements into an executable spec before writing code.

## Planning & Design

- **planning-and-task-breakdown**: Break work into discrete, verifiable tasks.
- **api-and-interface-design**: Contract-first interface design.
- **codebase-design**: Deep module vocabulary and design principles. Use when deciding where code goes.
- **wayfinder**: Chart a shared map of decisions for massive tasks spanning multiple sessions.

## Implementation

- **incremental-implementation**: Vertical slice execution discipline.
- **test-driven-development**: TDD loop with strict boundary testing (seams) and anti-tautological expected values.
- **source-driven-development**: Implementation driven by official documentation, not assumptions.
- **context-engineering**: Optimize agent context to maintain high output quality.

## Quality & Review

- **code-review**: Two-axis review (Spec compliance vs Standards) evaluating Correctness, Readability, Architecture, Security, and Performance.
- **debugging-and-error-recovery**: Standard error diagnosis for test failures and build breaks.
- **diagnosing-bugs**: Six-phase systematic diagnosis for hard bugs (race conditions, non-deterministic failures).
- **security-and-hardening**: Security-first development patterns (input validation, secrets).

## Delivery & Operations

- **git-workflow-and-versioning**: Git practices, branch strategy, and semantic versioning.
- **ci-cd-and-automation**: Pipeline setup and automated checks.
- **observability-and-instrumentation**: Production telemetry (logs, metrics, tracing).
- **shipping-and-launch**: Pre-launch checklist and rollout strategy.

## Continuity

- **handoff**: Write a handover document to pass state to the next agent session.
- **documentation-and-adrs**: Record architectural decisions in ADR format.
