2. NỘI DUNG COMMIT MESSAGE:
   -------------------------------------------------------------------------------------------------
   fix(dtc): resolve missing TX snapshot visibility and sanitize CVC Excel definedNames

   Root Cause Analysis:
   1. Snapshot Display & Export (ISO 14229 causality):
      - Cause: txtDetailFullFrame in DTC.xaml has MaxHeight="80" (~2-3 visible lines).
      - The legacy format string placed Received before Transmitted ("{0}: {1}\n\n{2}: {3}").
      - Long Received snapshot payloads (59 04 ...) spanned 3-4 lines, pushing the Transmitted frame below the vertical scroll fold and creating the impression that Transmitted was missing.
      - For 19 02 frames without snapshots, only the raw received frame was stored without recording the TX request frame (19 02 <maskByte>).

   2. CVC DTC Resolution ('not defined'):
      - Cause: General/DTC/VF9NP/CVC.xlsx contained invalid Defined Names ([388]他材料費, \, \\).
      - ClosedXML v0.105.0 automatically invokes FormulaParser upon opening, throwing ClosedXML.Parser.ParsingException.
      - An empty catch { } block swallowed the exception, resulting in an empty dictionary (Count = 0).
      - Consequently, all CVC DTC codes (e.g., U1881-83) failed candidate lookup and rendered as 'not defined'.

   Solutions Implemented:
   1. Snapshot Standardization:
      - Reordered snapshot formatting to strictly place Transmitted before Received across both UI and Excel export.
      - Added NormalizeSnapshotOrder supporting multilingual prefixes (vi, en, zh, ko, ar) to reorder legacy snapshots.
      - Enhanced 19 02 fallback to include both TX request ("19 02 <maskByte>") and RX response ("59 02 <maskByte> <FullFrame>").
   2. Excel Stream Sanitization:
      - Added OpenSanitizedExcelStream using System.IO.Compression.ZipArchive to strip <definedNames> nodes from xl/workbook.xml in RAM (< 1ms) prior to ClosedXML parsing.
      - Preserves original vendor Excel files on disk while eliminating FormulaParser crashes.
      - Verified 797 rows and 2,727 DTC keys loaded successfully (U1881-83 resolved to 'Incorrect CRC  FCAM_ESA_Sts(0x13a)').
   3. Additional MITM & Gateway Enhancements:
      - Synced live AliveCounter for E2E-protected frames in MitmEngine.
      - Synchronized UI override states and auto-switched to Inject mode upon signal override in SIMULATE.
      - Added hardware TX queue flush handling and settling delays for Vector CAN/CAN-FD drivers.
