2. TỔNG QUAN ĐỌC HIỂU DỰ ÁN (PROJECT ARCHITECTURE & CORE MODULES)
--------------------------------------------------------------------------------
- Tên hệ thống: CANForge / Tool Đọc DTC DID EBUS
- Mục tiêu: Cung cấp giải pháp toàn diện cho chẩn đoán UDS trên xe buýt điện (EBUS) và mô phỏng / can thiệp mạng CAN/CAN-FD ở chế độ Man-in-the-Middle (MITM).
- Các module cốt lõi:
  1) Chẩn đoán UDS (ISO 14229 / ISO 15765-2):
     - DTC.xaml / DTC.xaml.cs: Đọc mã lỗi (0x19), xóa lỗi (0x14), tra cứu tên DTC đa ngôn ngữ (VI, EN, KO, ZH, AR) và file định nghĩa lỗi.
     - DID.xaml / DID.xaml.cs: Đọc thông tin DID (0x22), ghi DID (0x2E), hỗ trợ giải mã System DID, VIN, Hardware/Software version.
     - DIAG.xaml / DIAG.xaml.cs: Quản lý phiên chẩn đoán (0x10), TesterPresent (0x3E), RoutineControl (0x31), ECU Reset (0x11).
     - DATA_ECU.xaml / DATA_ECU.xaml.cs: Quản lý danh mục định danh các hộp ECU trên mạng CAN.
     - GETKEY.xaml / SeedKeyHelper.cs: Thuật toán bảo mật SecurityAccess (0x27) tính Key từ Seed.
  2) Mô phỏng & Can thiệp MITM Bus CAN / CAN FD:
     - VectorCANManager.cs: Giao tiếp CAN Classic qua Vector XL Driver API V3.
     - VectorCANFdManager.cs: Giao tiếp CAN FD qua Vector XL Driver API V4, hỗ trợ dual bitrate (500k/2M), 64-byte payload, CAN FD DLC 0..15.
     - MitmEngine.cs: Bộ điều phối thời gian thực với timeBeginPeriod(1):
       * Pass-through: CH1 Listen-Only -> CH2 TX với độ trễ < 1ms.
       * Inject / Modify: Can thiệp tín hiệu (SignalEncoder - Intel/Motorola), tự động tính E2E CRC8 SAE J1850 + tăng Alive Counter (E2EHelper), độ trễ < 3ms.
       * Block / Drop: Lọc bỏ frame theo ID.
       * Echo Filter: Loại bỏ loopback frame trong cửa sổ 10ms.
  3) Ma trận DBC & Tín hiệu:
     - DbcParser.cs & DbcModels.cs: Phân tích các file ma trận CAN Classic BEV (Info, Body, PT, Chassis) và CAN FD EP (ICAN, BCAN, CCAN, PCAN).
     - SignalEncoder.cs: Đóng gói tín hiệu theo thứ tự bit Intel LSB / Motorola MSB.
  4) Bảo mật & Tiện ích:
     - LicenseHelper.cs: Mã hóa RSA 2048-bit xác thực bản quyền gắn với Machine ID.
     - LocalizationManager.cs & LocExtension.cs: Đa ngôn ngữ (5 ngôn ngữ).
     - ExcelHelper.cs: Xuất báo cáo chuyên nghiệp qua ClosedXML.
